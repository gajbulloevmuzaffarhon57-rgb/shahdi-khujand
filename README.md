# Shahdi Khujand — полный сайт

Запуск:

1. `cd backend`
2. `npm install`
3. Если папки `data` нет: `mkdir data`
4. `npm start`
5. Открыть `http://localhost:3000`
6. Админка: `http://localhost:3000/admin`
